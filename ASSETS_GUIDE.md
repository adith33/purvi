# 🌸 Farha's Birthday Surprise - Asset Replacement Guide

Hi Adith! Here is how to easily connect your real photos, song, and birthday banner:

### 📁 Where to place your files:
Copy your files into the `/public` folder with these exact names:

1. **Farha's First Photo:**
   - File path: `public/photo1.jpg`
   - Used in: Welcome section and First Photo cinematic blur reveal

2. **Farha's Second Photo:**
   - File path: `public/photo2.jpg`
   - Used in: Scrapbook polaroid memory section

3. **Farha's Third Photo (Lotus Grace & Serenity):**
   - File path: `public/photo3.jpg`
   - Used in: Dedicated Lotus Serenity portrait section

4. **Existing Birthday Banner Image:**
   - File path: `public/happy-birthday-farha.png`
   - **Note:** Stays completely hidden until Farha cuts the cake, then dramatically explodes into view!

4. **Farha's Favorite Song:**
   - File path: `public/farha-song.mp3`
   - Starts when she taps **"Open Your Surprise 💗"**
   - Note: If this file hasn't been added yet, the website automatically plays a soothing music-box chime melody as a built-in fallback so sound never breaks.

---

### ✍️ Customizing Messages:
You can customize any message, appreciation card, thank-you note, letter paragraph, or nickname in:
`src/config.ts`

### 📱 Live Preview Testing:
In the live preview window, you can also tap the **"Asset Setup / Guide"** button at the bottom-left to select your local files directly in browser memory to test them immediately!
